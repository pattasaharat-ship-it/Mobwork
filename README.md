# โต๊ะงานสายเที่ยว (เว็บแอป)

เว็บแอปจัดการลูกค้า โปรเจกต์ ตารางงาน และการเงิน สำหรับเพจ เที่ยวจนปวดหลัง / ขอนแก่นพลัส / กินที่ขอนแก่น
เปิดได้จากเบราว์เซอร์ทุกเครื่อง และเพิ่มลงหน้าจอโฮมของมือถือได้เหมือนแอปทั่วไป

## ตั้งค่าครั้งเดียว

1. **Supabase**: เปิด SQL Editor แล้วกด New query วางไฟล์ `supabase/setup.sql` ทั้งไฟล์แล้วกด Run
2. **Supabase**: ไปที่ Authentication > URL Configuration แล้วตั้ง **Site URL** เป็นลิงก์ของแอป (เช่น `https://<ชื่อ>.github.io/<repo>/`) เพื่อให้ลิงก์ยืนยันอีเมลและลิงก์รีเซ็ตรหัสผ่านพากลับมาที่แอป
3. **config.js**: ใส่ Project URL และ anon public key (อยู่ที่ Project Settings > API)
   ห้ามใส่ `service_role` key เด็ดขาด
4. **GitHub**: ไปที่ Settings > Pages > Source แล้วเลือก Deploy from a branch, `main`, `/ (root)` จากนั้นกด Save

## หลังเปิดใช้

- คนแรกกด "สมัครใช้งาน" แล้วจะกลายเป็นเจ้าของทีม
- คนในทีมกดสมัครด้วยอีเมลของตัวเองก่อน แล้วเจ้าของไปเพิ่มเขาที่ ตั้งค่า > ทีมงาน
- เมื่อทุกคนสมัครครบแล้ว ปิดการสมัครใหม่ได้ที่ Supabase > Authentication > Sign In / Providers > ปิด "Allow new users to sign up" เพื่อกันคนนอกสมัครเข้ามา (คนนอกที่สมัครเข้ามาจะได้ทีมว่างของตัวเอง และมองไม่เห็นข้อมูลทีมคุณอยู่แล้ว)
- ย้ายข้อมูลจากแอปเวอร์ชันใน Claude: ที่แอปเดิมกด ตั้งค่า > สำรองข้อมูลทั้งหมด แล้วที่แอปนี้กด ตั้งค่า > นำเข้าจากไฟล์สำรอง

## เพิ่มลงหน้าจอมือถือ

- **iPhone (Safari)**: กดปุ่มแชร์ แล้วเลือก "เพิ่มไปยังหน้าจอโฮม"
- **Android (Chrome)**: กดเมนู ⋮ แล้วเลือก "ติดตั้งแอป" หรือ "เพิ่มลงในหน้าจอหลัก"

## ความปลอดภัย

- ข้อมูลทุกแถวผูกกับทีม และ Row Level Security ใน Postgres อนุญาตให้อ่านหรือเขียนได้เฉพาะสมาชิกทีมนั้น
- anon key ตั้งใจให้อยู่ฝั่งหน้าเว็บได้ เพราะไม่มีสิทธิ์ข้ามกฎ RLS

## ไฟล์

- `index.html`: ตัวแอป สร้างจาก `../tools/creator-desk.source.html` ด้วย `python3 ../tools/mkweb.py ../tools/creator-desk.source.html index.html`
- `config.js`: ค่าการเชื่อมต่อ Supabase
- `supabase/setup.sql`: ตาราง กฎความปลอดภัย และฟังก์ชันทีม (รันซ้ำได้)
- `manifest.webmanifest`, `sw.js`, `icons/`: สำหรับติดตั้งเป็นแอปบนมือถือ
- `vendor/`: supabase-js 2.45.4
